# GatherEase MVP PRD

## 핵심 정보

**목적**: 소규모 그룹 모임 주최자가 참여 관리·공지·정산을 한 곳에서 처리하여 카카오톡 단톡방의 혼란과 수동 정산의 번거로움을 해소한다
**사용자**: 수영·헬스·등산 동호회 운영자 및 번개·소풍·파티를 자주 여는 친구 모임 주최자 (모임 규모 5~30명)

---

## 사용자 여정

```
1. 랜딩 페이지
   ↓ "모임 만들기" 버튼 클릭

2. 모임 생성 페이지
   ↓ 모임명·날짜·장소·최대인원·설명 입력 후 "생성" 버튼 클릭
   ↓ host_token을 localStorage에 저장

3. 모임 홈 페이지 (주최자 뷰)
   ↓ 고유 URL + 6자리 초대 코드 발급 화면 확인
   ↓ 초대 링크를 카카오톡·메시지 등으로 공유

   [참여자 흐름]
   공유된 링크 클릭 → 모임 홈 페이지 (비참여자 뷰)
   ↓ "참여하기" 버튼 클릭

4. 참여 등록 페이지
   ↓ 닉네임 입력 + 참여 상태 선택 (참여/미정/불참)
   ↓ participant_token을 localStorage에 저장
   ↓ "등록 완료" 버튼 클릭

5. 모임 홈 페이지 (참여자 뷰)
   ├── "공지/댓글" 탭 클릭 → 공지 목록 페이지
   └── "정산" 탭 클릭 → 정산 관리 페이지 (주최자만 편집 가능)

6. 공지 목록 페이지
   ├── 주최자: 공지 작성 → 공지 등록 완료 → 공지 목록 페이지로 복귀
   └── 참여자: 댓글 작성 → 댓글 등록 완료 → 동일 페이지 유지

7. 정산 관리 페이지
   ↓ 주최자: 비용 항목 입력 → 1/N 자동 계산 → 납부 완료 체크
   ↓ "정산 결과 공유" 버튼 클릭
   → 정산 결과 공유 링크 생성 → 완료
```

## 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명           | 설명                                                                              | MVP 필수 이유                               | 관련 페이지                      |
| -------- | ---------------- | --------------------------------------------------------------------------------- | ------------------------------------------- | -------------------------------- |
| **F001** | 모임 생성        | 모임명·날짜/시간·장소·최대 인원·설명을 입력하고 고유 URL과 6자리 초대 코드를 발급 | 서비스의 핵심 시작점, 없으면 모든 기능 불가 | 모임 생성 페이지                 |
| **F002** | 초대 링크 공유   | 생성된 고유 URL을 복사하거나 외부 공유 가능하도록 제공                            | 참여자 유입의 유일한 경로                   | 모임 홈 페이지                   |
| **F003** | 참여 등록        | 링크 클릭 후 닉네임 입력과 참여 상태(참여/미정/불참) 선택으로 등록 완료           | 로그인 없는 참여자 경험의 핵심              | 참여 등록 페이지                 |
| **F004** | 참여자 목록 조회 | 참여/미정/불참 탭으로 구분된 참여자 목록 표시, 주최자는 참여자 삭제 가능          | 주최자가 인원 현황을 즉시 파악              | 모임 홈 페이지                   |
| **F005** | 대기자 명단 관리 | 최대 인원 초과 시 참여 신청자를 자동으로 대기자 명단으로 이동                     | 인원 초과 시 혼란 방지                      | 모임 홈 페이지, 참여 등록 페이지 |
| **F006** | 공지 작성        | 주최자만 텍스트 공지를 작성하고 모임 홈 상단에 최신 공지 1개 노출                 | 공지 묻힘 문제 해소                         | 공지 목록 페이지, 모임 홈 페이지 |
| **F007** | 공지 목록 조회   | 전체 공지를 시간 역순으로 조회                                                    | 과거 공지 확인 필요                         | 공지 목록 페이지                 |
| **F008** | 댓글 작성·삭제   | 모든 참여자가 공지에 댓글 작성 가능, 본인(localStorage)·주최자만 삭제             | 참여자 소통 채널 제공                       | 공지 목록 페이지                 |
| **F009** | 비용 항목 입력   | 주최자가 항목명과 금액을 여러 건 입력                                             | 정산의 시작점                               | 정산 관리 페이지                 |
| **F010** | 1/N 정산 계산    | 입력된 총 비용을 참여자 수로 균등 분배하여 인당 금액 자동 계산                    | 주최자의 수동 계산 실수 제거                | 정산 관리 페이지                 |
| **F011** | 납부 완료 체크   | 주최자가 참여자별 납부 완료 여부를 체크                                           | 미납자 추적 가능                            | 정산 관리 페이지                 |
| **F012** | 정산 결과 공유   | 정산 결과 화면을 별도 공유 링크로 제공                                            | 참여자에게 정산 내역 전달                   | 정산 관리 페이지                 |

### 2. MVP 필수 지원 기능

| ID       | 기능명                 | 설명                                                                             | MVP 필수 이유              | 관련 페이지                                                                            |
| -------- | ---------------------- | -------------------------------------------------------------------------------- | -------------------------- | -------------------------------------------------------------------------------------- |
| **F013** | localStorage 토큰 식별 | host_token(주최자)·participant_token(참여자)을 localStorage에 저장하여 권한 구분 | 로그인 없는 인증 대체 수단 | 모임 생성 페이지, 참여 등록 페이지, 모임 홈 페이지, 공지 목록 페이지, 정산 관리 페이지 |
| **F014** | 랜딩 페이지            | 서비스 소개 및 모임 만들기 진입점 제공                                           | 신규 사용자 첫 접점        | 랜딩 페이지                                                                            |

### 3. MVP 이후 기능 (제외)

- 회원가입 / 로그인 (localStorage 토큰으로 대체)
- 카풀 신청·매칭 (Phase 3, 복잡도 높음)
- 푸시 알림 (초기 불필요)
- 이미지 첨부 (Phase 2, 스토리지 관리 복잡)
- 맞춤 정산 (1/N으로 80% 해결)
- 반복 모임 설정 (단순 복사로 대체)
- 프리미엄 수익 모델 (MVP 이후 검증)

## 메뉴 구조

```
GatherEase 내비게이션

공개 영역 (인증 불필요)
├── 랜딩 페이지
│   └── 기능: F014 (서비스 소개 및 모임 만들기 진입)
└── 모임 만들기
    └── 기능: F001 (모임 생성 및 초대 코드 발급)

모임 내부 메뉴 (/event/[id] 진입 후)
├── 모임 홈
│   └── 기능: F002, F004, F005, F006, F013 (참여자 목록·최신 공지·초대 링크)
├── 참여하기
│   └── 기능: F003, F005, F013 (닉네임 입력·참여 상태 선택)
├── 공지·댓글
│   └── 기능: F006, F007, F008 (공지 목록·작성·댓글)
└── 정산
    └── 기능: F009, F010, F011, F012 (비용 입력·1/N 계산·납부 체크·공유)
```

## 페이지별 상세 기능

> **구현 기능:** `F014` | **접근:** 누구나 (공개)

| 항목            | 내용                                                                                                              |
| --------------- | ----------------------------------------------------------------------------------------------------------------- |
| **역할**        | 서비스의 첫 진입점으로 가치 제안을 전달하고 모임 생성으로 안내                                                    |
| **진입 경로**   | 직접 URL 접속 또는 북마크                                                                                         |
| **사용자 행동** | 서비스 설명 확인 후 "모임 만들기" 버튼 클릭                                                                       |
| **주요 기능**   | - 서비스 핵심 가치(3분 모임 생성, 앱 설치 불필요) 설명<br>- 사용 흐름 간략 소개<br>- **"모임 만들기"** 버튼 (CTA) |

| **사용자 행동** | 주최자: 비용 항목 입력·납부 체크·결과 공유, 참여자: 정산 내역 및 납부 현황 조회                                                                                                                                                                                                                                            |

| **다음 이동**   | 공유 버튼 클릭 → 링크 복사 완료 토스트 표시, 나머지 액션은 동일 페이지 유지                                                                                                                                                                                                                                                |

## 데이터 모델

### events (모임)

| 필드             | 설명             | 타입/관계   |
| ---------------- | ---------------- | ----------- |
| id               | 고유 식별자      | UUID        |
| title            | 모임명           | text        |
| description      | 모임 설명        | text        |
| event_date       | 모임 날짜·시간   | timestamptz |
| location         | 장소             | text        |
| max_participants | 최대 인원        | integer     |
| host_token       | 주최자 식별 토큰 | text        |
| invite_code      | 6자리 초대 코드  | text        |
| created_at       | 생성 일시        | timestamptz |

### participants (참여자)

| 필드              | 설명                                           | 타입/관계   |
| ----------------- | ---------------------------------------------- | ----------- |
| id                | 고유 식별자                                    | UUID        |

## localStorage 토큰 설계

로그인 없이 주최자·참여자를 식별하는 핵심 메커니즘:

| 토큰              | 저장 시점         | 저장 키                     | 용도                                            |
| ----------------- | ----------------- | --------------------------- | ----------------------------------------------- |
| host_token        | 모임 생성 완료 시 | `gg_host_{event_id}`        | 주최자 권한 (공지 작성, 참여자 삭제, 정산 편집) |
| participant_token | 참여 등록 완료 시 | `gg_participant_{event_id}` | 참여자 식별 (본인 댓글 삭제, 참여 상태 변경)    |

- 토큰 값은 UUID v4 형식으로 클라이언트에서 생성 후 DB에 함께 저장
- 동일 브라우저에서 재방문 시 localStorage 값과 DB 비교로 권한 복원
