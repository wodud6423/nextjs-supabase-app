## 1. 문제 (Problem)

**해결하려는 핵심 고통점**

- 카카오톡 단톡방에서 모임 공지가 채팅에 묻혀 찾기 어려움
- 참여 인원 파악을 위한 수동 집계(댓글 세기, DM 확인)가 번거로움
- 정산 시 1/N 계산을 수작업으로 하고, 미납자 추적이 어려움

**기존 대안 (Existing Alternatives)**

- 카카오톡 단톡방 공지 기능 (묻힘 문제 미해결)
- 엑셀/구글 시트 수동 정산
- 카카오페이 정산 요청 (참여 관리와 분리됨)

---

## 2. 고객 세그먼트 (Customer Segments)

**주요 사용자**

- 수영·헬스·등산 동호회 운영자 (정기 모임, 5~30명 규모)
- 번개·소풍·파티를 자주 여는 친구 모임 주최자

**얼리 어답터 (Early Adopters)**

- 디지털 툴에 익숙하고, 카카오톡 그룹 관리에 불편함을 느끼는 20~40대 모임 주최자
- 월 1회 이상 정기적으로 모임을 주최하는 동호회 운영진

---

## 3. 가치 제안 (Unique Value Proposition)

> **앱 설치 없이, 링크 하나로 모임 참여·공지·정산을 3분 만에**

- 카카오톡 링크 클릭만으로 앱 설치 없이 참여 등록 완료
- 모임 생성부터 초대 링크 공유까지 3분 이내
- 참여 현황·공지·정산을 하나의 URL에서 통합 관리
- 로그인 불필요 → 참여자 진입 장벽 제로

---

## 4. 해결책 (Solution)

**PRD 기능과의 연계**

| 고통점             | 해결책                                                 | 관련 기능              |
| ------------------ | ------------------------------------------------------ | ---------------------- |
| 공지 묻힘          | 모임 홈 상단 최신 공지 고정 노출 + 공지 목록 페이지    | F006, F007             |
| 인원 파악 번거로움 | 참여/미정/불참/대기자 탭별 자동 분류                   | F003, F004, F005       |
| 수동 정산          | 비용 항목 입력 → 1/N 자동 계산 → 납부 체크 → 공유 링크 | F009, F010, F011, F012 |
| 참여자 소통 부재   | 공지별 댓글 기능 (모든 참여자 작성 가능)               | F008                   |
| 참여 등록 불편     | 닉네임만 입력하면 즉시 등록 (로그인 불필요)            | F003, F013             |

## 5. 경쟁우위 (Unfair Advantage)

**복제하기 어려운 차별점**

- **로그인 불필요 설계**: localStorage 토큰으로 권한 식별 → 참여 장벽 최소화
- **3분 완성 UX**: 모임 생성~초대 링크 공유의 극단적 단순함
- **단일 URL 통합**: 정산·공지·참여 관리가 하나의 모임 URL에 집약 (타 서비스는 각각 분리)
- **카카오톡 공유 최적화**: 링크 클릭 즉시 참여 가능한 모바일 퍼스트 UX

---

## 6. 수익 흐름 (Revenue Streams)

**MVP 단계**

- 무료 제공 (사용자 확보 및 재사용률 검증 우선)

**MVP 이후 검토 (Phase 2+)**

- 프리미엄 플랜: 모임 개수 무제한, 고급 정산 기능(맞춤 정산, 이미지 첨부)
- 팀/단체 구독 요금제: 동호회·소모임 단체 계정
- 광고 없음 (UX 우선 원칙)

---

## 7. 비용 구조 (Cost Structure)

**고정 비용**

- Supabase 호스팅 (DB + 실시간 구독): 무료 티어 → 트래픽 증가 시 유료 전환
- Vercel 배포: 무료 티어 (개인 프로젝트)
- 도메인 비용: 연간 약 1~2만원

**변동 비용**

- DB 쿼리 및 스토리지 사용량 (Supabase)
- Vercel 서버리스 함수 실행 횟수

**초기 비용**

- 개발 인건비 (솔로 개발 기준 MVP: 약 2~3주)

---

## 8. 주요 지표 (Key Metrics)

**핵심 성과 지표 (KPI)**

| 지표               | 목표                              | 측정 방법                      |
| ------------------ | --------------------------------- | ------------------------------ |
| 모임 생성 수       | 주간 10건 이상                    | events 테이블 count            |
| 생성→공유 완료율   | 3분 이내 80% 이상                 | 생성~첫 참여자 등록 시간 측정  |
| 참여자 등록 전환율 | 링크 클릭 대비 60% 이상           | participants count / 방문자 수 |
| 재사용률           | 첫 10팀 중 50% 2회 이상 모임 생성 | 동일 host_token의 events count |
| 정산 완료율        | 모임당 정산 기능 사용 40% 이상    | expense_items 입력 여부        |

**MVP 성공 기준 (PRD)**

- 주최자 1명이 모임 생성 → 초대 링크 공유까지 3분 이내
- 참여자가 앱 설치 없이 링크 클릭만으로 전 기능 사용
- 첫 사용자 10팀 온보딩 후 재사용률 측정

---

## 9. 채널 (Channels)

**획득 채널 (Acquisition)**

- 카카오톡·문자·SNS를 통한 초대 링크 바이럴 확산 (핵심 채널)
- 동호회 커뮤니티 (네이버 카페, 밴드, 카카오 오픈채팅) 입소문
- 구글/네이버 검색 SEO ("모임 관리", "소모임 정산" 키워드)

**유지 채널 (Retention)**

- 이전 모임 링크 북마크 재방문
- 주최자의 반복 모임 생성 (동일 브라우저 localStorage 복원)
